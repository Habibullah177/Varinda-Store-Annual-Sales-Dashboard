# 📊 Varinda Store Annual Sales Dashboard 2024

An interactive Excel dashboard created to analyze Varinda Store's annual sales and order performance.

The dashboard turns raw sales data into simple visual insights using Pivot Tables, Pivot Charts, Slicers, and Excel data visualization.

## 🎯 Project Purpose

The purpose of this project is to understand store sales and customer behavior through data.

I created this dashboard to analyze:

- Monthly sales and orders
- Sales by gender
- Order status
- Top-performing states
- Age and gender analysis
- Sales by channel
- Category performance

The goal was to make the raw data easier to understand through an interactive dashboard.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Data Visualization

## 📊 Dashboard Features

### 1. Order vs Sales

Shows monthly order count and sales amount to understand the sales trend throughout the year.

### 2. Men vs Women

Shows the contribution of male and female customers to total sales.

### 3. Order Status

Shows the distribution of orders based on their current status, including:

- Delivered
- Returned
- Cancelled
- Refunded

### 4. Top 5 States

Shows the top-performing states based on sales.

### 5. Age vs Gender

Analyzes sales across different age groups and genders.

### 6. State Wise / Channel Analysis

Shows how sales are distributed across different channels and locations.

### 7. Interactive Filters

The dashboard includes filters for:

- Months
- Channel
- Category

These filters allow users to interact with the dashboard and view specific parts of the data.

## 💡 Key Insights

Some observations from the dashboard include:

- Women contribute a larger share of sales than men.
- Delivered orders represent the majority of orders.
- Maharashtra appears among the highest-performing states in the Top 5 States analysis.
- Amazon represents a significant share of the sales channels shown in the dashboard.
- Sales and order volume change across different months.
- Customer sales patterns vary across different age groups and genders.
